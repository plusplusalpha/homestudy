# PA Home Study

브라우저에서 실행되는 3D 가구 배치 스터디입니다. 별도 빌드 과정 없이 GitHub Pages에 바로 올릴 수 있습니다.

## 폴더 구조

- `index.html` — 화면 구조
- `assets/css/` — UI 스타일
- `assets/images/` — 도면과 공간 참고 이미지
- `js/` — 3D 공간, 가구, 저장·공유 기능
- `js/vendor/` — Three.js 런타임

## GitHub Pages 배포

1. 이 폴더의 내용 전체를 저장소 최상위에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**를 **GitHub Actions**로 선택합니다.
4. Actions의 `Deploy static site to Pages` 작업이 끝나면 공개 주소가 생성됩니다.

배치는 브라우저에 슬롯 3개로 저장할 수 있고, **현재 배치 링크 복사**로 같은 구성을 URL에 담아 공유할 수 있습니다.
